# Contributing

Documentation corrections and website improvements are welcome.

1. Create a focused branch.
2. Update the relevant website or documentation source.
3. Run `npm test`, `npm run build`, and `npm run licenses:check`.
4. Open a pull request explaining the user-facing impact.

Use this repository's issues for website and documentation problems. Report application behavior, runtime bugs, and feature requests in the [LoopTroop application repository](https://github.com/looptroop-ai/LoopTroop/issues).

By participating, you agree to follow the [Code of Conduct](CODE_OF_CONDUCT.md).
